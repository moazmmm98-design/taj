# تقييم — حلقات المخيم القرآني

واجهة **React + Vite** لتقييم الطلاب اليومي في حلقات المخيم القرآني.
عربية بالكامل (RTL)، بخط **IBM Plex Arabic**، مع دعم الوضع الليلي و responsive للجوال والتابلت والويب.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء الإنتاج إلى dist/
npm run preview  # معاينة بناء الإنتاج
```

## الأدوار والدخول

- **شاشة دخول** واحدة بتبويبين: **معلّم** / **مشرف**.
- **المعلّم** يدخل **برمز حلقته الفريد** فقط → يصل مباشرةً إلى طلاب حلقته، ولا يرى غيرها.
- **المشرف** يدخل بكلمة مروره → لوحة المشرف. ومنها يُدير **أكواد دخول الحلقات** (توليد تلقائي / تعديل يدوي / نسخ).
- بيانات تجريبية: كلمة مرور المشرف `admin1234`؛ أكواد الحلقات تظهر داخل لوحة المشرف.

> ⚠️ **أمنياً:** الفحص هنا في الواجهة **تمثيلي للنموذج فقط**. في الإنتاج تُخزَّن كلمات المرور مُجزّأة (hashed) في الخادم، ويُفرض تقييد الوصول على مستوى الـ API (التوكن يحمل صلاحية الحلقة).

## المزايا

- تقييم سريع بضغطة واحدة لكل عنصر (مقياس ١–٥ ملوّن)
- انتقال تلقائي لأول طالب غير مُقيَّم بعد الحفظ
- نسخ تقييم الأمس ثم التعديل
- بحث فوري + شريط تقدّم + حالة كل طالب (تم / بانتظار)
- ملاحظات مع شرائح جاهزة + ملاحظة صوتية (Web Speech API)
- اختصارات لوحة المفاتيح على الويب: `١-٥`، الأسهم، `Enter`
- الوضع الليلي + Skeleton Loading + Toast

## التخزين والبيانات

- **الوضع التجريبي (افتراضي):** بلا مفاتيح Supabase، يعمل التطبيق ببيانات وهمية في الذاكرة (تُفقد عند التحديث) — مناسب للتطوير والعرض.
- **الوضع الدائم (Supabase):** عند ضبط `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`، تُحفظ الحلقات والطلاب والأكواد والتقييمات في قاعدة بيانات Postgres وتُشارَك عبر الأجهزة.
- طبقة الوصول للبيانات معزولة في `src/api/repo.js` و`src/lib/supabase.js`.
- **خطوات الإعداد الكاملة (المخطط SQL + المتغيّرات + النشر):** راجع `docs/supabase-setup.md`.
- تسجيل الدخول يبقى بالرمز (رمز الحلقة للمعلّم + كلمة مرور المشرف)؛ نقطة `login()` في `src/App.jsx` جاهزة لاستبدالها بمصادقة حقيقية لاحقاً.
